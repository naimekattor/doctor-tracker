# Doctor Tracker

A web application to track doctors, appointments, and schedules.

## Project Structure

```
doctor_tracker/
├── backend/    # Express.js REST API & MongoDB database
├── frontend/   # Client application
└── README.md
```

## Getting Started

### Backend Setup

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   pnpm install
   ```
3. Create a `.env` file based on `.env.example`:
   ```bash
   cp .env.example .env
   ```
4. Start development server:
   ```bash
   pnpm run dev
   ```
